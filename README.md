# Página Pessoal - Sobre Mim

## Sobre o projeto

Este projeto foi desenvolvido como uma atividade de HTML com o objetivo de criar uma página pessoal simples e organizada.

A página apresenta algumas informações sobre mim, meus hobbies e meus objetivos para o futuro profissional.

## Estrutura da página

A página foi dividida em algumas partes para deixar o conteúdo mais organizado:

* **Cabeçalho (`header`)**: apresenta o título "Sobre Mim" e uma breve descrição da página.
* **Conteúdo principal (`main`)**: reúne as principais informações da página.
* **Seções (`section`)**: dividem o conteúdo em três assuntos: sobre mim, meus hobbies e meu futuro profissional.
* **Rodapé (`footer`)**: apresenta a identificação da página e o ano.

## Tags utilizadas

Durante o desenvolvimento foram utilizadas algumas tags semânticas do HTML:

* `<header>` para o cabeçalho;
* `<main>` para o conteúdo principal;
* `<section>` para separar os assuntos;
* `<h1>` para o título principal;
* `<h2>` para os títulos das seções;
* `<p>` para os textos;
* `<footer>` para o rodapé.

O uso dessas tags ajuda a deixar o código mais organizado e facilita a compreensão da estrutura da página.

## Estilização

Também foi utilizado CSS dentro do próprio arquivo HTML para fazer alguns ajustes visuais, como:

* Escolha da fonte;
* Espaçamento entre os elementos;
* Organização da largura do conteúdo;
* Alinhamento do cabeçalho e do rodapé;
* Cor de fundo do rodapé.

A página foi mantida com um visual simples, para que o foco continuasse sendo a estrutura e o uso correto das tags HTML.

## Comentário reflexivo

No código também foi incluído um comentário explicando a importância das tags semânticas utilizadas. Essa parte mostra como cada elemento contribui para organizar o conteúdo e melhorar a compreensão da página.

## Conclusão

Com essa atividade, pude praticar a criação de uma página utilizando HTML semântico e entender melhor a função de cada elemento. Também foi possível perceber que uma boa organização do código ajuda a deixar a página mais clara e fácil de entender.
